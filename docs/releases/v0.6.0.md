local transcription with whisper, speaker separation with diarizen, and two text formats.

download the [source zip](https://github.com/annie-bennie/transcriber/archive/refs/tags/v0.6.0.zip)
and extract it. with python 3.10–3.12 or `uv` installed, open a terminal in the project folder.

**windows (powershell)**

```powershell
.\install.ps1
.\transcribe.bat "class.mp4" --language ru
```

**linux**

```sh
sh install.sh
sh transcribe.sh "class.mp4" --language ru
```

replace `ru` with the language of your recording. the installer checks which device
will be used. the first run downloads the models. the transcript and its json go in
the `transcripts` folder next to the recording.

add `--format lecture` for a paragraph per speaker change. to export that format again,
pass the saved json in place of the recording. the default format includes timestamps
and measurements.
