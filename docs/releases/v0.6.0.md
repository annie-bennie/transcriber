local transcription with whisper, speaker separation with diarizen, and two text formats.

### install from the wheel

create and activate a python 3.10–3.12 environment. for a cpu installation, run:

```sh
python -m pip install torch==2.8.0+cpu torchaudio==2.8.0+cpu --extra-index-url https://download.pytorch.org/whl/cpu
python -m pip install "https://github.com/annie-bennie/transcriber/releases/download/v0.6.0/transcriber-0.6.0-py3-none-any.whl"
transcribe --check
transcribe "class.mp4" --language ru
transcribe "transcripts/class.json" --format lecture
```

the last command writes `transcripts/class_lecture.txt` using the saved speaker labels.
for environment setup on windows or linux and the nvidia gpu install command, see the
[wheel instructions for v0.6.0](https://github.com/annie-bennie/transcriber/blob/2045b30/README.md#install-from-the-wheel).

### install from source

download the [source zip](https://github.com/annie-bennie/transcriber/archive/refs/tags/v0.6.0.zip)
and extract it. with python 3.10–3.12 or `uv` installed, open a terminal in the project folder.

**windows (powershell)**

```powershell
.\install.ps1
.\transcribe.bat "class.mp4" --language ru
```

**linux**

```sh
sh install.sh
sh transcribe.sh "class.mp4" --language ru
```

replace `ru` with the language of your recording. the installer checks which device
will be used. the first run downloads the models. the transcript and its json go in
the `transcripts` folder next to the recording.

add `--format lecture` for a paragraph per speaker change. to export that format again,
pass the saved json in place of the recording. the default format includes timestamps
and measurements.
